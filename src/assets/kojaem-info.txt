KoJaem 의 이름은 고재민이야. 그의 Github 닉네임은 KoJaem 이야.

KoJaem은 인천에 살고있어. 그의 생일은 1998년생 11월29일이야.

KoJaem의 키는 181cm 야.

KoJaem의 발사이즈는 280cm야.

KoJaem의 옷사이즈는 L~XL야. 참고로, 그는 의외로 패션에 관심이 많아.

KoJaem은 한세대학교 컴퓨터공학과를 졸업했어. 학교에서 가장 흥미롭게 한것은 교내 웹개발 동아리(감자) 활동이야.

KoJaem은 새로운 기술을 배우는것을 좋아하고, 사이드 프로젝트 하는것을 좋아해.

KoJaem은 요즘 프론트엔드 웹 개발 전반적인 내용들과 React Native WebView 를 관심있게 공부하고 있어.

KoJaem의 기술스택은 HTML, CSS, JavaScript, TypeScript, React, NextJs, Styled-components, TailwindCss, Recoil, React-Query, SWR, AWS, Figma, Notion 등 여러가지가 있어.

KoJaem이 가장 좋아하는 음식은 치킨이야.

KoJaem은 싫어하는 음식은 없지만, 토마토를 썩 좋아하지는 않아.

KoJaem과 빠르게 친해지는 방법은 프로젝트를 같이 진행하는거야. 그는 지인과 사이드 프로젝트를 하는것을 좋아해.

KoJaem은 나중에 1~2인 개발로 서비스를 운영 해보고싶다는 목표가있어.

KoJaem의 MBTI 는 ISTJ야.

KoJaem이 좋아하는 계절은 겨울이야.

KoJaem의 이상형은 자기일을 열심히하는 배울점이 있는사람이고 눈이 예쁜사람을 좋아해.

KoJaem과 다른 개발자와의 차이점은 퇴근후에도 꾸준히 성장한다는거야.그는 그가 개발자로서 성장하는것을 즐기고있어.

KoJaem은 카페에서 주로 아이스아메리카노를 마셔.

KoJaem은 CloudHospital에서 SaaS 기반 홈페이지 빌더의 프론트엔드 개발을 담당했었고, 실제로 50개 고객에서 1000개 이상으로 서비스가 확장되는 경험을 했어.

KoJaem은 NextJs의 getServerSideProps에서 API 병렬 호출을 적용해 로딩 속도를 약 49% 개선한 경험이 있어.

KoJaem은 GPT를 활용해 자동 번역 품질을 개선하는 등 업무에 AI 도구를 적극 활용하고 있어.

KoJaem은 다국어 및 RTL 지원을 위한 CSS 구조 설계를 직접 진행한 경험이 있어.

KoJaem은 PageSpeed Insight 및 Lighthouse를 통한 성능 분석과 개선을 즐겨서 하고 있어.

KoJaem은 On-Demand Revalidation 기능을 통해 SSG 페이지의 실시간 반영을 구현한 경험이 있어.

KoJaem은 Azure Search를 활용해 70만 개 이상의 URL로 구성된 사이트맵 제너레이터에서 잘못된점을 고쳐서 SEO를 개선한 경험이 있어.

KoJaem은 감자 동아리 활동을 통해 웹 기획부터 UI/UX 설계, 개발, 배포까지 프로젝트 전 과정을 경험해봤어.

KoJaem은 사이드 프로젝트에서 Notion과 Figma를 적극 활용하여 기획 및 협업을 효율적으로 관리하고 있어.

KoJaem은 사용자 경험에 집착하는 성향으로, 실제 사용자 피드백을 받아 지속적으로 기능을 개선하는 것을 중요하게 여기면서 개발을 진행해.

KoJaem은 코드의 유지보수성과 가독성을 매우 중요하게 생각하며, 이를 위해 코드 구조와 스타일 가이드를 꾸준히 다듬는편이야.

KoJaem은 퇴근 후 사이드 프로젝트 또는 스터디를 통해 하루의 성장을 기록하는 습관이 있어.

KoJaem은 "내가 만든 기능을 누군가가 실제로 사용하는 경험" 에서 큰 동기를 느껴.

KoJaem은 의견이 다를 때는 근거와 논리를 기반으로 소통하려고 노력해.

KoJaem은 산책하면서 음악 듣는 걸 좋아해. 집중이 잘 안될 땐 잠깐 밖에 나가 리셋하는 편이야.

KoJaem 은 최신 개발뉴스에 관심이 많아서 KoJaem 의 크롬을 열면 Google 이 아닌 hacker.dev 사이트가 나와.

KoJaem은 대외활동을 좋아해. 최근 대와활동으로는 DND 12기 4팀의 팀장으로 활동을 했어.

KoJaem 의 대표적인 대와활동 및 수상은 Microsoft & KDI 국제정책 대학원에서 주촤한 해커톤에서 2등으로 수상을 했어. 공무원 약 400명 앞에서 발표한 영상도 있어. 관련내용은 그의 Notion 에서 확인할 수 있어.
